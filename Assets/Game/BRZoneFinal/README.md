# Storm Crown — первый этап

Источник истины: StormZone.Instance.Center/Radius. Нижняя кромка следует OceanSurface.Height; сервер, урон, таймер и сетевые сообщения не изменены.

Resources/StormCrown.prefab автоматически создаётся в NetworkOcean. StormCrown отключает прежние визуальные объекты BRZoneV2/V3, не удаляя их ассеты. Новый меш: 256 сегментов × 32 вертикальных интервала. Профиль Height=160 м и InwardProfile в Inspector: 0/2/8/20/40/65/95 м смещения на высотах 0/20/40/70/100/130/160 м. При малом радиусе смещение ограничено 70% R: отверстие не закрывается.

Материал: premultiplied alpha, unlit, два широких мировых шума, тангенциальное движение и вертикальный дрейф. Top fade только последние 5%. BaseDensity, BroadScale, MediumScale, FlowSpeed доступны в Inspector.

Вторичные облака: Fog Particles, собственный материал, 42 переиспользуемых слота, детерминированный seed, сектор ±65°, неравномерные высоты, размеры и смещения. Waterline — отдельная полоса 8 м; локальные vapor/spray работают вблизи камеры. Исходники сторонних пакетов не изменены.

StormCrownDebug — временная камера для расстояний и ракурсов; не подключена к production prefab. DebugGizmos отображает нижнее, среднее и верхнее кольца, активный сектор.

Проверка Play Mode: нижний радиус отклоняется менее чем на 0,00013 м; высота — менее 0,000008 м. Ошибок шейдера нет. Скриншоты: Docs/StormFinal/index.html.

Статус: первая реализация систем 1–4, визуально не принята. Верхняя кромка ещё слишком ровная; cloud breakup выглядит пятнами; контакт воды слабее требуемого. Скриншоты основного комплекта сняты до последней настройки локального водяного пара; отдельный WaterVapor_50 показывает его усиление. Последнее поднятие полосы пены на 0,55 м и увеличение размеров vapor сохранены, но требуют повторного просмотра.

Дождь, молнии, AERO proximity, аудио и соответствующие Inspector controls не добавлены: следующий этап только после оценки основной формы, согласно инструкции пользователя. Не считать эти функции готовыми. Сетевая проверка и профиль GPU не выполнялись.
