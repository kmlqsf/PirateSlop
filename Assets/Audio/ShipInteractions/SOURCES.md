# Звуки взаимодействий Ship V3

Все исходные записи имеют CC0 1.0 и допускают использование в игре без обязательного указания автора. Источники сохранены здесь для проверки происхождения, без добавления титров в игру.

- `DiceTableSource.mp3`: [Dice roll, wooden table](https://freesound.org/people/ekfink/sounds/235489/). Короткие фрагменты движения по деревянному столу.
- `DiceCupSource.mp3`: [Dice (6) shake fast in cup](https://freesound.org/people/2BACH/sounds/185985/). Фрагменты столкновений костей и тряски в кружке.
- `CandleSource.mp3`: [Candle lighting](https://freesound.org/people/mfearnley/sounds/434145/). Отдельные фрагменты зажигания и задувания для свечи и фонарей.
- `BellSingleSource.mp3`: [Ship Bell Single Ring](https://freesound.org/people/Sojan/sounds/353233/).
- `BellDoubleSource.mp3`: [Ship Bell Two Chimes](https://freesound.org/people/Sojan/sounds/353232/). Два удара разделены на самостоятельные варианты.

Скачаны общедоступные HQ MP3 с CDN Freesound. Игровые WAV преобразованы в моно, обрезаны, нормализованы и имеют короткие плавные края. Лицензия: https://creativecommons.org/publicdomain/zero/1.0/

Повторная настройка: `ShipV3InteractionAudioSetup.Configure`. Существующий звук рынды сохраняется; добавлены три варианта без непосредственных повторов.
