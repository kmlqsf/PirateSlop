# Загрузчик контекста PirateSlop

Даёт короткую справку по механике без чтения всех скриптов и истории разработки. Работает без Unity, Blender, сети и дополнительных пакетов, в PowerShell 5.1 или 7.

Из папки PirateGame:

```powershell
./Tools/Context/context.ps1 пушки
./Tools/Context/context.ps1 паруса
./Tools/Context/context.ps1 -List
./Tools/Context/context.ps1 networking -Json
./Tools/Context/context.ps1 -Validate
```

Без темы выводится обзор. При запрете запуска скриптов текущей политикой можно выполнить одну команду через `powershell -NoProfile -ExecutionPolicy Bypass -File ./Tools/Context/context.ps1 пушки`; постоянная политика компьютера не меняется.

В Codex достаточно попросить «загрузи контекст пушек» или поставить задачу по механике: маршрут указан в AGENTS.md. Локальный навык pirateslop также использует этот загрузчик.

Корень определяется относительно скрипта, а не по пути конкретного компьютера. Можно передать `-ProjectRoot` для другой копии проекта. Загрузчик только читает файлы: не запускает редакторы, не меняет Git и не проверяет живую сцену.

Версия Unity, ссылки на сетевые пакеты, протокол, порт, лимит игроков, тестовый спавн и список включённых сцен читаются заново из файлов при каждом запуске. Это значения сохранённых файлов, а не текущая сессия или старая сборка. Отсутствующие источники и пути явно помечаются. Полные скрипты, сцены и префабы в отчёт не включаются.

Карта механик находится в `topics.json`: `id`, русские/английские `aliases`, короткие `notes`, точные пути `files` и тематические `docs`. При изменении структуры обновлять только соответствующую запись и запускать `-Validate`. Проверка подтверждает существование путей и уникальность имён, но не правильность подключения компонентов и не работоспособность игры.

`project.md` сохранён как справочник и история. Его полный текст не загружается по умолчанию. В отчёте ссылки для дальнейшего чтения, а не указание прочитать все перечисленные файлы. При неизвестной теме загрузчик выдаёт ошибку и предлагает список; он не угадывает механику и не сканирует проект.
