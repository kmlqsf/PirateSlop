# Инспектор Unity

Открыть **PirateSlop → Diagnostics → Focused Inspector**.

1. Выбрать объект в Hierarchy или префаб в Project.
2. Нажать **Inspect current selection**. Можно перетащить объект в поле Object / Prefab и нажать Inspect.
3. **Include children** включает первые 40 объектов поддерева, включая корень и неактивные объекты. **Component name filter** ограничивает компоненты, например `ShipController` или `Cannon`. **More field values** раскрывает больше полей.
4. **Copy report** копирует отчёт для отправки в чат. После изменения объекта нажать Inspect повторно.

Отчёт только читает состояние: компоненты, сериализованные параметры, ссылки, локальный Transform, состояние объекта и изменения относительно префаба. Unassigned — пустое поле, которое может быть необязательным или назначаться при запуске; MISSING REFERENCE и MISSING SCRIPT требуют проверки. Проверка ссылок охватывает видимые сериализованные поля выбранных компонентов; это не проверка игрового поведения или всех runtime-ссылок.

Сводка prefab overrides относится ко всему ближайшему корню экземпляра. У дочернего объекта указан путь к этому корню. Для префаба на диске отчёт описывает ассет; для объекта сцены — текущее состояние редактора, включая несохранённые значения.

## Вызов для Codex

Сначала подтвердить Unity MCP и правильный проект. Затем через `execute_code` выполнить один вызов:

```csharp
return PirateSlop.Editor.FocusedInspector.CaptureSelection();
```

Для известного префаба, без изменения выделения или сцены:

```csharp
return PirateSlop.Editor.FocusedInspector.CaptureAsset("Assets/Prefabs/Networking/NetworkShip.prefab", false, "ShipController");
```

Для уже полученного GameObject: `Capture(target, includeChildren, componentFilter, details, maxObjects)`. Не искать произвольный объект по неоднозначному имени. Начинать с одного объекта и конкретного компонента; расширять только по задаче.

Вывод ограничен примерно 18 тысячами символов, 40 компонентами на объект, 2000 свойствами на компонент и 40 объектами по умолчанию (максимум 200). Обрезка явно отмечена TRUNCATED. При ней сузить цель; отсутствие ошибок в частичном отчёте не означает полную проверку. Инспектор не запускает игру, не исправляет ссылки и не сохраняет сцену.
