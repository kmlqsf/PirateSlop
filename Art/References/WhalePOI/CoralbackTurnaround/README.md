[Выбранный исходный концепт](ApprovedConcept.png). Сундук отсутствует; его модель и анимация крышки будут отдельными. Коралловая площадка сохранена пустой.

Набор представляет один выбранный дизайн с четырёх направлений. Это изображения концепта; они не получены вращением уже существующей 3D-модели.

Визуальная проверка visual_reviewer: APPROVED после исправления обозначений боков. Камеры немного приподняты; мелкие пятна и отдельные кораллы не совпадают буквально между видами. Крупная форма кита, плавники, хвост, пустая площадка и её заметная асимметрия согласованы.

[12 вариантов взаимодействия с сундуком, цикл рывков и погружения](LootInteractionOptions.md).

Варианты лутания — предложение для обсуждения. Код, текущие ассеты Unity и Blender-модель не менялись. Начальное предложение по времени: 75 секунд доступного окна, усиление движения к концу, полное погружение и уход при любом исходе. Рекомендованный первый вариант — освобождение коралловых скоб рычагом с возможностью прерывать работу ради хвата.
