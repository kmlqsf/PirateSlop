# Модели личного оружия

`FirearmAssemblies.blend` содержит три собранные модели с упакованными PBR-текстурами. Исходные FBX и текстуры из предоставленных архивов находятся в `Sources`. Активный исходник корабля не заменяется.

`AssembleFirearms.py` выполняется внутри открытого Blender через MCP: собирает отдельную сцену, экспортирует FBX в `Assets/Models/Firearms` и сохраняет редактируемый BLEND. Длины корпуса: пистолет 0,45 м, снайперка 1,18 м, дробовик 0,72 м. В каждой модели один спуск; кремнёвые замки справа у пистолета и снайперки, зеркальная пара у дробовика.

В Unity масштаб пистолета 0,72, снайперки и дробовика — 0,9: итоговые длины корпуса 0,324, 1,062 и 0,648 м. Подтверждённый хват длинного оружия сохранён. Игровой NetworkPlayer использует канонические Visual-префабы с GripSocket_Firearm и SupportSocket_Firearm. Рукоять совмещается с правой ладонью, точка поддержки — с левой; WeaponArmRig ограничивает обе цели по длине рук, задаёт положение кистей и локтей. Пистолет имеет отдельную точку хвата; кисть следует наклону рукояти, пальцы используют позу New_PistolAim. CharacterActions не переносит ActionProp старого PirateRig на Mixamo. Ready/Aim/Reload используют позу текущего скелета, отдача и движение при перезарядке добавляются NetworkEquipment. Старые ActionModel оставлены для прежних привязок -X/+Z; видимый шомпол удалён.

Для подключения экспортов в Unity: `PirateSlop > Replace Firearm Models`. `FirearmModelReplacementSetup` сохраняет существующие GUID игровых префабов и назначает модели игроку. Дуло визуала берётся из сборки; настройки баллистики сохранены. Геометрия нормализуется в метры, ствол направлен по +Z, правая сторона по +X. Материалы используют исходные карты цвета/нормалей и Metallic/Smoothness. NewPirateAnimationBatch сохраняет новые назначения поз при переимпорте анимаций.

У снайперки отдельный ShoulderSocket_Firearm на затыльнике приклада. В стойке WeaponArmRig совмещает его с плечом текущего скелета, сохраняя отдачу и движение оружия. Левый хват перенесён на цевьё; при нехватке длины руки его точка сдвигается вдоль цевья, без смещения приклада. При перезарядке плечевая привязка освобождается. Эти сокеты сохраняются повторным импортом.

`FirearmMechanism` получает возраст выстрела и состояние перезарядки из действующих компонентов. Удар происходит через 0,065 с; кремнёвый курок возвращается на -12° относительно исходной позы и восстанавливается в конце перезарядки. Спуск нажимается и возвращается; искры воспроизводятся только для подходящего первого или третьего лица. Стрельба, урон, боезапас, прицел и анимации рук используют прежние системы.

Основной `ShipV3Test` выдаёт дробовик и снайперку из `ExperimentalShipEquipment`, повторяя спавн после подбора. Пикапы лежат на боку и следуют за кораблём через `NetworkFish`; механики качения ядер у них нет. Пистолет остаётся стартовым предметом игрока. Повторный импорт корабля добавляет эти две точки через `LootModelReplacementSetup.ConfigureImportedShip`.

Игровая и сетевая проверка выполняется пользователем; Play Mode при замене не запускался.
