# Акула из Tripo

Исходник предоставлен пользователем: `Blender/Акула/акула.zip` рядом с игровым проектом. FBX и пять оригинальных карт сохранены в TripoSources. В архиве нет скелета и клипов. Исходные текстуры и форма сохраняются.

PrepareTripoShark.py запускается внутри открытого Blender через проверенный TCP MCP bridge, готовит модель в отдельной сцене SharkTripoWork и возвращает прежнюю активную сцену. Длина 5.2 м, 9570 вершин, 9 костей; раздельные веса тела, хвоста, плавников и нижней челюсти. Shark_Swim содержит волну изгиба хвоста и лёгкое движение плавников; Shark_Bite добавляет движение челюсти и небольшой наклон головы. Редактируемый результат SharkTripoRig.blend сохраняется копией, игровой экспорт — Assets/Models/Shark/SharkTripo.fbx.

SharkTripoSetup в Unity импортирует Generic rig и оба клипа, включает loop только для Swim, назначает оригинальные basecolor и normal и упаковывает metallic + 1-roughness для URP. Существующий Shark.controller сохраняет параметры Biting/Bite, SharkVisual.prefab сохраняет GUID. Акулы смотрят по игровому +Z. Три экземпляра патрулируют, преследуют, кормятся у рыбы и уходят после открытия/переноса сундука. Серверный SharkAttackRpc запускает короткий выпад и укус ближайшей акулы; прежний урон 25 и отвлечение рыбой на 10/15 с сохранены.

Изменения входят только в общую Windows-сборку. Игровая/сетевая/визуальная приёмка не запускалась.
