# Веса головы нового пирата

Игровая модель: `Assets/Models/Characters/NewPirate/Walking.fbx`. На неё ссылается `NetworkPlayer.prefab`.

В `Pirate_HeadWeights.blend` сохранена сцена `PirateWeightRepair` с исправленными весами. Лицо и борода следуют за `mixamorig:Head`; у основания головы сохранён плавный переход. Исправлены 2451 из 9010 исходных вершин.

В исходном Mixamo-риге подбородок и борода имели значительные веса Neck/Spine2. Сильное вращение Head в сабельных клипах растягивало эту область.

`repair_head_weights.py` выполняется внутри подключённого Blender. Функция `repair(source_fbx, output_fbx, source_blend)` использует импортированную модель в сцене `PirateWeightRepair` и исходный FBX с тем же порядком вершин. Маска рассчитана на эту конкретную сетку. При повторном запуске из сохранённого BLEND сначала сверить масштаб и координаты с исходным FBX.

Экспорт изменяет только массивы весов и индексов кластеров, а также служебные FileId/CreationTime. Скрипт проверяет точное сохранение геометрии, UV, скелета, bind poses и анимаций. В Unity сохранены GUID, mesh fileID, геометрия и bind poses; ссылка игрового префаба действует.

Исходный загруженный `Blender/New_pirate/pirate/Walking.fbx` за пределами проекта сохранён без изменений. Play Mode не запускался; удары саблей проверить вручную с видом от третьего лица.
