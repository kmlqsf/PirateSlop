# Поддержка предметов ботами

Матрица по InventoryItem, этап 7, базовое покрытие завершено. Подбор предмета не означает умение его применять. Работоспособность в игровом матче требует ручной проверки.

| Предмет | Реализованное применение | Осталось |
| --- | --- | --- |
| Рыба | Лечение свободного бота на палубе: обычные 3 секунды, расход одной рыбы, отмена при угрозе/уроне | Лечение во время вылазки |
| Ром | Доставка имеющегося рома на полку своего корабля до её вместимости | Самостоятельное решение о воскрешении существующего участника |
| Пистолет, сабля | Личный бой на своей палубе, перезарядка, перемещение | Бой на берегу и абордаж |
| Комплект пушки | Подбор, перенос, установка через общую серверную операцию | Тактическое переоснащение |
| Обычное ядро | Доставка, зарядка, артиллерийский выстрел | Расширенные тактики |
| Молоток | Ремонт палубных повреждений и корпуса с воды | Игровая проверка всех типов повреждений |
| Доски | Нет отдельного применения; текущий ремонт не расходует доски, CanAddItem их отклоняет | Согласовать с будущей механикой ремонта |
| Удочка | Свободный бот на остановленном корабле пробует заброс, подсекает и вытягивает штатный улов | Выбор отдельного места рыбалки, игровые проверки |
| Огненное, ледяное, отталкивающее ядра | Выбор носителя боеприпаса по дистанции видимой цели, зарядка из настоящего инвентаря, выстрел с проверкой союзников | Игровая проверка, расширенный выбор по состоянию цели |
| Возвращающееся ядро | Зарядка, прямое наведение без гравитации, проверка возврата при попадании и промахе | Игровая проверка, уточнение прогноза при резком маневрировании кораблей |
| Вино | Выпивает перед длинным возвращением с острова; маршрут и подход к лестнице учитывают бег по воде | Игровая проверка окончания эффекта в пути |
| Мушкет, двустволка | Выбор по дистанции, штатная стрельба и перезарядка, проверка союзников с учётом разброса | Бой вне собственной палубы; игровая проверка |
| Попугай-бомба | Запуск, серверное управление к видимой цели, уход вверх при потере видимости, штатный взрыв | Обход препятствий, игровой прогон |
| Крюк | Захват противника на своей палубе и освобождение перед ближним боем | Межкорабельные переходы |
| Абордажный крюк | Зарядка и выстрел на малой дистанции, подтягивание троса до 25 м, освобождение штатными ударами | Высадка абордажной группы |
| Рыба-меч | Бросок по видимой цели 5–30 м, расчёт дуги и проверка союзников | Игровая проверка; самостоятельный повторный подбор |
| Рыба-фугу | Бросок с прогнозом отскоков, таймера и взрыва при воде, проверкой области урона | Игровая проверка при движущихся препятствиях |
| Святая граната | Поджог непосредственно перед выпуском, остановка при попадании, прогноз точки вспышки и полного радиуса ослепления союзников | Игровая проверка силы/длительности ослепления |

Мортира подключена к артиллеристу: высокая баллистическая дуга, штатная зарядка/темп и проверка области взрыва. Нужна игровая проверка. Доски остаются исключением самой игры: подбор отключён, ремонт их не расходует; новую механику расхода бот не вводит.
