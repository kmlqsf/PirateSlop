# PirateSlop — один контрольный тест четырёх кораблей

Этот пакет предназначен для первого измерения актуальных оптимизаций на другом ПК. Unity и исходники не нужны. Распакуйте весь архив в отдельную папку: одного PirateSlop.exe недостаточно.

Актуальный CPU-пакет от 16.10.2026 помечен `cpu-work-v1` в manifest и новом JSON/TXT-отчёте. Старый архив `PirateSlop-Fleet4-20261016-142933.zip` его не содержит. Для нового замера нужны все файлы свежего `Builds/WindowsRelease`; состояние сборки указано в начале OptimizationPlan.md. Сам новый пакет ещё ожидает измерения FPS.

## Что запустить

Для дополнительного сравнения в FullHD используйте отдельный `RunFleet4-FullHD.cmd` рядом с PirateSlop.exe: он принудительно задаёт1920×1080 в оконном режиме, тотже4/12разбор60с иD3D11. Игру предварительно закрыть. Окно не разворачивать/не менять размер; прочие настройки графики сохраняются. Сборка заново не нужна. Этот дополнительный.cmd подготовлен после первоначальногоZIP и в старый архив автоматически не добавляется; передать его отдельно. Лог: Fleet4-FullHD-Player.log. Фактическое разрешение проверять по JSON/TXT.

1. Запустите PirateSlop.exe. В настройках графики выберите обычное разрешение своего монитора и полноэкранный режим. Не переключайте специально в QHD. Render scale — 1; «Оптимизация облаков и зоны» — включена. Остальные настройки пока оставьте привычными: они попадут в отчёт. Запишите или сфотографируйте выбранные настройки.
2. Закройте игру. Запустите RunFleet4.cmd рядом с exe. Скрипт автоматически выберет четыре корабля / 12 синтетических персонажей, Direct3D11, отключит VSync и ограничение FPS только на время теста. Разрешение скрипт не задаёт. Эти диагностические параметры не отключают принятые оптимизации.
3. Дождитесь загрузки, 20 секунд подготовки и 60 секунд записи. Оставьте игру активным окном, не сворачивайте и не переключайтесь на другие приложения. Управление камерой автоматическое. Во время записи отдельные группы объектов будут временно исчезать — это штатное измерение стоимости систем.
4. Игра завершится и откроется папка отчётов. При успешном тесте сохранены два новых файла с одинаковым временем: `*-isolation.json` и `*-isolation.txt`. Пришлите оба, а также `Fleet4-Player.log` из папки игры и сведения о выбранном разрешении/настройках.

Один прогон достаточен для первого разбора. Второй и третий пока не нужны. Escape отменяет тест; CANCELLED/INVALID не используются как успешный контроль. Если тест завершился ошибкой, пришлите сохранённые файлы и лог, не пытайтесь многократно повторять его.

Альтернатива без скрипта: главное меню → «Диагностика» → «Тесты флота» → «4 / 12» → «Разбор нагрузки · 60 с». При таком запуске заранее отключите VSync и ограничение FPS в настройках, затем после теста нажмите кнопку открытия папки отчётов. Не выбирайте «Тест производительности», «Тест флота · 120 с», «Разбор корабля · 66 с» или стресс водоворота для этого первого контроля.

## Как читать результат

Нас интересуют обычные состояния в начале/конце и стоимость отключённых систем по участкам. Средний FPS всей последовательности отключений не равен FPS обычной игры. Этот сценарий — неподвижный флот в открытой воде, а не бой, не проверка десяти кораблей и не стресс водоворота.

Название этапа `No ship cloth and ropes` означает остановку обновления ткани и процедурных верёвок. Их уже построенная геометрия остаётся на экране; статические верёвки модели тоже видны. Этот этап не измеряет полную стоимость отрисовки всех верёвок. Для другого этапа `No ship rendering` отключается отображение кораблей целиком.

Отчёты сохраняются в `%USERPROFILE%\AppData\LocalLow\DefaultCompany\PirateSlop\PerformanceReports`. Старые отчёты удалять не требуется — выбирайте файлы по времени нового запуска. При другом пути запуска/учётной записи ищите папку, открытую игрой.

Не включайте Unity Profiler и диагностический HUD для контрольного измерения. Не меняйте графику во время записи. Если Steam необходим для запуска, оставьте его запущенным. Не обновляйте драйверы и не меняйте системные настройки специально ради этого первого контроля.

Пакет использует текущие сохранённые игровые исходники и ассеты, включая оборудование/геометрию корабля, GPU-сетки, HUD и прежние принятые оптимизации. Попадания/урон/ragdoll не оптимизировались. Manifest рядом с exe фиксирует конкретную сборку и состав архива.
