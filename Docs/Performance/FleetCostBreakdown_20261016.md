# Флот: причина ограничений FPS, 16.10.2026

Проверены короткие причинные срезы в Release на Ryzen 7 7800X3D / RTX 3070 Ti, 2560×1440, scale1, VSyncOFF, ProfilerOFF, HUDOFF. Живые корабли и по3синтетических персонажа безAI. У каждого запуска20с прогрева после готовности мира и60с записи. Первые2с каждого6с состояния исключены. Файлы имеют UTC-дату15октября; работа выполнена16октября поМоскве.

Экономию строк не складывать. Скрытие кораблей одновременно убирает их геометрию/тени/часть skinning и прекращает обновления, зависящие отisVisible. Это ещё не точная разбивка «корпус против материалов». Скрытие поверхности воды оставляет WaterManager buffers/caustics и физику. Мелкие изменения общего кадра особенно в первом4-корабельном срезе ограничены drift9.26%; устойчивее большие разницы и собственные CPU-фазы. Отключения предназначены только для диагностики.

## Что изменено

- Канаты вне видимости обновляют косметический tube mesh5Гц; при видимости, включая тени, возвращается прежняя частота. Первыйmesh строится сразу. Коллизии и взаимодействия не менялись.
- Растительность вне видимости обновляет косметическое покачивание5Гц. Ограничение разрешено только при отсутствии collider в вращаемомCoastalVisual;5используемых префабов проверены нативно. Деформация шейдером ветра продолжает работать.
- Щупальца сохраняют каждую физическую позу и атаки. Повторные чтения направлений/rotation корня заменены однократным чтением вEvaluatePose. На204позахкостей максимальное отличие0.014мм, срабатывания атаки совпали. Это preview-проверка, не сетевая приёмка.

На4кораблях LateUpdate снизился с6.55–6.88до4.50–4.69мс; первый короткий baseline показал57–63→75–77FPS. На10кораблях LateUpdate7.75–7.78→6.11–6.50мс, но устойчивого выигрыша общегоFPS нет. Пакет уменьшает конкретный CPU-расход; принимать его за решение задачи120FPS нельзя.

## Следующий приоритет

1. Стоимость представления корабля: отдельно GPU skinning/ткань, геометрия и проходы материалов, CPU отправка renderers. Нужен профиль конкретного ракурса4кораблей, а не новый полный пролёт или ещё одна правка статических канатов. Не возвращать автоматически прежние193МБLOD-копии, которые не дали общегоFPS.
2. Для слабогоПК получить этот же60с срез на новой сборке: «Диагностика → Тесты флота → 4/12 → Разбор нагрузки». Сначала его обычное разрешение; разрешение фиксируется в отчёте. Это один прогон, не серия изтрёх. На нашемПК нельзя подтвердить его личный прирост.
3. Водоворот и контакты исследовать отдельным коротким сценарием после обычного флота. Попадания по людям/кораблям остаются отложенными.

Свободная игра, поворот камеры с появлением скрытых канатов/растительности, второй клиент и15мин боя остаются открытыми проверками. Короткий диагностический режим не заменяет их.
