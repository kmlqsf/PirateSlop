# Небо обычной тестовой карты

Обычная тестовая карта из меню использует солнечный день, закат и мягкую лунную ночь. В F8 появился ползунок «Небо: день → закат → лунная ночь» и кнопки двух крайних состояний. Ползунок задаёт состояние, переход сглаживается; автоматического течения времени нет. Настройка локальная для визуального эксперимента.

Система создаётся только через `EnvironmentTestGallery.SpawnInto`. Обычная игровая карта, Boat Attack Water Test и Oceana Water Test её не создают. `SkyDayNight.prefab` содержит солнце, луну и глобальный Volume. `TestSkyDayNight` временно использует отдельный `TestSkyPipeline`, отключает прежние направленные источники света и восстанавливает освещение, отражения, туман и pipeline при выходе. Runtime Volume использует копию профиля.

День: солнце 55°, интенсивность 3.03. Ночь: луна на высоте 24°, видимый азимут 125°, интенсивность 0.55, мягкие тени. Ночная экспозиция неба −0.35, окружающая подсветка (.34, .40, .52) до перевода в linear. Лунный диск 0.9° использует float-порог, чтобы малая окружность не исчезала из-за округления в half. Передача основного света происходит при нулевой интенсивности. Облака имеют постоянную форму: Custom, плотность 0.38, основание 2800 м, толщина 1200 м, ветер 10 км/ч. Во время перехода снижено накопление предыдущих кадров облаков.

Вода обычного теста отражает текущий динамический cubemap PBSky вместо дневного OceanSkyReflection. Ночью её базовые цвета и пена плавно затемняются до 18%; прозрачность сохраняется. Исходные параметры runtime-материала восстанавливаются при выходе. Основной материал океана не изменяется.

Морская дымка использует PBSky Fog; старый полноэкранный Sea Mist отключён только в копии renderer. Существующий ползунок «Морской туман» в F8 управляет плотностью нового тумана. Обычный shader fog выключен на время эксперимента, чтобы не удваивать дымку.

Источники под MIT:

- [UnityPhysicallyBasedSkyURP](https://github.com/jiaozi158/UnityPhysicallyBasedSkyURP), исходная ревизия `f8f1f3fbc4708f378252b6188ce416a57ccd06af`, embedded package 1.0.4. Сохранена лицензия; добавлены `moonBody` и `ambientFloor`, луна без солнечного flare, исключены старые методы проходов для Unity 6.3+.
- [UnityVolumetricCloudsURP](https://github.com/jiaozi158/UnityVolumetricCloudsURP): используется уже существующая копия `Assets/Tests/StormCloudBakeoff/CandidateA/VolumetricClouds`; её исходники не заменены. Материал для неба скопирован отдельно.

Для повторной подготовки ассетов: `PirateSlop > Prepare Test Sky`. Команда создаёт/обновляет только тестовые профиль, material, renderer, pipeline и prefab. Она не переключает открытую сцену.

Проверка вручную: открыть обычную тестовую карту через меню, нажать F8, провести ползунок от дня до ночи и обратно, оценить солнце, закат, луну, облака, освещение палубы и отражения воды. Проверить «Морской туман» и возврат обычного освещения после выхода. Сборка, Play Mode и визуальная приёмка автоматически не выполнялись.
