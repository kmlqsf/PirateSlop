- Ограниченный архипелаг для морского боя: 3 км в диаметре, 24 локации по умолчанию.
- Шесть типов без внешних моделей: песчаный остров, высокий скалистый остров, бухта-полумесяц, атолл с лагуной, подводный риф, морская скала.
- Процедурные меши, коллайдеры, подводные склоны, плоское глубокое дно и материал песка/земли/скал по высоте и уклону.
- Разделение локаций водными проходами, свободная центральная область и зарезервированные старты кораблей.
- Защита кинематического корабля от прохода через сушу/мелководье и выхода за радиус карты.
- Точки с устойчивыми ID: `ship_spawn`, `land_spawn`, `loot`, `landmark`, `underwater_poi`.
- Профиль карты, отдельные ассеты типов локаций, правила размещения точек и необязательных статических префабов.
- Seed хоста, JSON-описание, версия генератора, подпись каталога, сверка контрольной суммы геометрии перед появлением игрока.
- Построение по одной локации за кадр, прогресс загрузки, поддержка позднего подключения и повторного создания сессии.
- Карта на M и экспорт/повторная загрузка описания.

Внешние модели, текстуры и пакеты не скачивались: вся геометрия и раскраска создаются проектом.

## Где менять параметры

`Assets/Settings/World/DefaultWorld.asset`:

| Поле | Назначение |
|---|---|
| Seed / RandomSeed | Seed по умолчанию и случайный seed для хоста |
| FixedLayout | Необязательный JSON, имеющий приоритет над seed |
| Radius | Радиус области навигации кораблей |
| LocationCount | Число локаций |
| Resolution | Число ячеек на сторону меша локации |
| SeaDepth | Глубина общего дна |
| ShippingGap | Дополнительное расстояние между внешними границами локаций |
| SpawnClearance / SpawnSpacing | Запас воды вокруг старта и расстояние между стартами |
| Locations | Каталог включённых типов |
| CatalogRevision | Повышать при изменении содержания подключённых префабов |

Готовые `LocationDefinition` находятся в той же папке. Радиус и высота выбираются из диапазонов; Roughness меняет берег и рельеф. Weight определяет частоту. Если число локаций позволяет, каждый тип с положительным весом появляется хотя бы один раз; Weight=0 отключает тип.

В сетевом меню хост может задать целочисленный seed; пустое поле использует настройки профиля. Также поддерживается аргумент `-seed 17421`. Для локальной SampleScene используется Seed профиля. Профиль закреплён на объекте `ProceduralWorld` в обеих сценах.

## Добавление типа локации

1. Создать ассет через Create → PirateSlop → World → Location Type либо скопировать существующий.
2. Назначить уникальный Settings.Id, форму, диапазоны радиуса/высоты, цвета, Roughness и Weight.
3. Настроить Points и добавить ассет в Locations профиля.

Вариации существующих форм не требуют C#. Для принципиально новой топологии расширить `Landform` и функцию `WorldGenerator.Height`; увеличить `WorldLayout.CurrentVersion` и версию сетевого протокола. Размещение, создание меша, коллайдеры и передача описания продолжат использовать общий путь.

## Точки и будущие объекты

Каждый PointRule задаёт Tag, Count, диапазон высот относительно моря, MaxSlope и Spacing. Count — максимальное число: если подходящей поверхности нет, точка не создаётся. Обязательными в V1 являются только старты кораблей; генерация отклоняет карту, в которой они не помещаются.

`ProceduralWorld.Instance.Points("loot")` возвращает данные точек, событие `Generated` сообщает об окончании построения. В иерархии также создаются `WorldSpawnPoint` с Id и Tag. Для размещения на меше используется фактическая высота его треугольников. Теги можно добавлять свободно; `ship_spawn` зарезервирован генератором.

StaticPrefab предназначен только для статического окружения, одинакового у всех. Не подключать к нему NetworkObject или скрипт самостоятельного появления сетевых предметов. Настоящий лут, NPC, разрушаемые объекты и новые варианты респауна должны создаваться отдельной серверной системой на выбранных точках. Сейчас маркеры лута не создают предметы, а land_spawn не заменяет существующий респаун на корабле.

После замены содержимого StaticPrefab увеличить PrefabVersion правила или CatalogRevision профиля и обновить обе игры. Геометрия этих префабов не входит в контрольную сумму процедурного рельефа.

## JSON и воспроизводимость

`Assets/Settings/World/ExampleMap.json` — сформированный пример seed 17421 с 24 локациями и стартами на 32 корабля.

Меню PirateSlop → World → Export Map Layout сохраняет текущую игровую карту; вне Play Mode создаёт описание по настройкам профиля. Импортировать JSON как TextAsset и назначить FixedLayout для повторения. Удалить ссылку для возвращения к генерации по seed. JSON содержит расположение, параметры каждой локации и точки; его можно редактировать, сохраняя версию и допустимые значения.

Это сохранение исходной карты, не сохранение состояния игрового мира. Для разрушений/подобранных предметов потребуется отдельный список изменений по стабильным ID.

## Сеть

Хост строит описание и геометрию до запуска сервера. После авторизации клиент получает полное описание; строит коллайдеры, вычисляет SHA-256 описания и квантованных высот мешей и подтверждает готовность. Только после совпадения подписи появляются корабль и персонаж. Клиент с другим каталогом/геометрией не допускается. Поздний клиент получает ту же карту. Для сети нужен протокол 9 на обоих ПК.

Изменения seed, размещения или порядка случайных вызовов не затрагивают UnityEngine.Random: генератор использует собственный PRNG. Высоты квантованы до миллиметра. Сверка геометрии обнаруживает различия платформ/версий вместо допуска к разным коллайдерам.

## Ограничения V1 и ручная приёмка

Это конечная карта без бесконечного стриминга, эрозии, пещер, деревьев, зданий и системы задач. Рифы — геометрия каменного мелководья, без моделей кораллов. Плотность мешей единая на локацию; отдельные LOD пока отсутствуют. Корабль останавливается перед непроходимым мелководьем, без симуляции повреждения киля. Проверка корпуса приближённая, по девяти точкам. M показывает схему расположения, а не точную береговую линию.

Скрипты импортированы и скомпилированы, ассеты и обе сцены сохранены. Сформирован пример JSON. Play Mode, сборка и многоклиентная приёмка не запускались.

Проверить вручную: создание сессии с seed, M, видимость островов, подход к берегу, ходьбу/плавание, непроходимость суши кораблём, совпадение карты у второго игрока, позднее подключение, переподключение и создание новой сессии с другим seed. Для прежней камеры и корабля SampleScene свободная центральная область оставлена пустой.
